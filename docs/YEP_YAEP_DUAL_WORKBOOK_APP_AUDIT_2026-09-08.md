# YEP + Y.A.E.P. DUAL WORKBOOK / APP PROOF AUDIT

Date: 2026-09-08
Owner: A/1 Suppliers
Purpose: Make the proof-of-concept uniform across the tablet app and two matching participant workbooks.

## Proof Structure
The proof must visibly support two separate program groups:

1. YEP — Young Entrepreneurs Process — ages 7-17
   - Foundation: ages 7-10
   - Builder: ages 11-13
   - Momentum: ages 14-17

2. Y.A.E.P. — Young Adult Entrepreneur Process — ages 18-24

The two programs share the same core Process structure, but wording, examples, challenge framing, and workbook prompts should fit the age group.

## Required Proof Package
- Tablet app with visible YEP and Y.A.E.P. pathway selection
- YEP ages 7-17 proof workbook
- Y.A.E.P. ages 18-24 proof workbook
- Matching app/workbook terminology
- Matching activity sequence
- Matching completion/progress logic
- Admin Review that identifies program and age pathway
- Sample/non-sensitive proof data only

## Shared Core Sequence
Both workbooks and the app should follow the same proof order:

1. Welcome / What the Process Is
2. Power Name / identity
3. Mirror Check-In
4. Daily Quest
5. Week 1 Module
6. S.T.E.M.Sin / technology connection
7. FINISHER Focus
8. Reflection
9. XP / Progress
10. Boss Challenge
11. Mentor Spotlight / Mentor Question
12. Rewards / Badges
13. My Process Page
14. Admin / facilitator proof view

## Workbook 1 — YEP Ages 7-17
Use youth-friendly language without making the material childish.

Required Week 1 proof content:
- Power Name
- Define Your Why
- Identity Map
- Daily Quest: Problem Spotter
- Boss Challenge: 60-Second Solution
- Mentor Question
- Quest Starter badge
- Identity Builder badge
- Boss Move badge

The workbook should include visible callouts showing when the participant switches to the app.

Example:
WORKBOOK: Write your problem.
APP: Open Daily Quest → Problem Spotter → save your response.

## Workbook 2 — Y.A.E.P. Ages 18-24
Use young-adult, workforce, business, money, and execution language.

Required Week 1 proof content:
- Power Name / professional or entrepreneurial identity
- Define Your Why
- Asset Map
- Daily Quest: Opportunity Spotter
- Boss Challenge: 60-Second Value Pitch
- Strategic Mentor Question
- Quest Starter badge
- Identity Builder badge
- Boss Move badge

Example:
WORKBOOK: Identify one real market, workplace, or community opportunity.
APP: Open Daily Quest → Opportunity Spotter → record who it affects and the value you could create.

## App / Workbook Audit Method
For every workbook page, mark:

- PASS — app screen exists and matches
- GAP — workbook asks for something the app does not support
- MISMATCH — app and workbook both contain the step but wording, sequence, or completion differs
- APP ONLY — app has a proof step with no workbook companion
- WORKBOOK ONLY — workbook has a proof step with no app companion

## Proof-of-Work Standard
A reviewer should be able to see:

WORKBOOK ENTRY → MATCHING APP ACTION → SAVED PROGRESS → BADGE / STATUS → ADMIN REVIEW

The proof should make clear that the program is not just a presentation. The participant work, app interaction, progress record, and facilitator view should connect visibly.

## What Must Be True Before Upload / Demonstration
- Both workbooks exist as separate files
- YEP workbook clearly says ages 7-17
- Y.A.E.P. workbook clearly says ages 18-24
- App lets the demonstrator select both pathways
- Y.A.E.P. is not presented as merely another youth age tier
- App and workbook names match
- App and workbook order match
- No workbook promises a feature the proof app does not have
- No app proof feature exists without an explanation or corresponding workbook purpose
- Admin Review shows which pathway is active
- All proof data is sample/non-sensitive
